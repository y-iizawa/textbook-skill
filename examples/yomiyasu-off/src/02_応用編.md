## 第2章 正規方程式 — 行列表現

### 2.1 解の閉じた形

計画行列を $X$、観測ベクトルを $\mathbf{y}$ とすると、係数ベクトル $\boldsymbol{\beta}$ は次で与えられます：

$$
\hat{\boldsymbol{\beta}} = (X^\top X)^{-1} X^\top \mathbf{y}
$$

この式が、全ての線形回帰の土台を支えています。$X^\top X$ が正則でないと、解は暴れてしまいます。そのため、多重共線性には注意が必要です。

```python
import numpy as np
beta = np.linalg.solve(X.T @ X, X.T @ y)  # $ はここでは数式扱いされない
```
