## 第2章 正規方程式 — 行列表現

### 2.1 解の閉じた形

計画行列を $X$、観測ベクトルを $\mathbf{y}$ とすると、係数ベクトル $\boldsymbol{\beta}$ は次の式で求まります。

$$
\hat{\boldsymbol{\beta}} = (X^\top X)^{-1} X^\top \mathbf{y}
$$

この式は、線形回帰の計算の基本形です。$X^\top X$ が正則でないと逆行列が存在せず、解が一つに決まりません。説明変数どうしが強く相関する多重共線性があると、この状態に近づきます。

```python
import numpy as np
beta = np.linalg.solve(X.T @ X, X.T @ y)  # $ はここでは数式扱いされない
```
